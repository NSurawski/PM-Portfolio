Feature Prioritizer

A visual prioritization tool that helps PMs score, rank, and communicate feature priorities using proven frameworks (RICE, ICE, Value vs. Effort) — designed for fast, shareable decision-making.

v1.0

Target User
IC PMs & PM Leaders

Purpose & Vision

A visual prioritization tool that helps PMs score, rank, and communicate feature priorities using proven frameworks (RICE, ICE, Value vs. Effort). Designed for individual PMs who need a fast, shareable way to make and defend prioritization decisions.

Problem Statement

PMs constantly face the question: “Why are we building X instead of Y?” Most teams rely on spreadsheets or gut instinct. Spreadsheets lack visualization, are hard to share, and don’t enforce consistent scoring. This leads to:

  • Inconsistent prioritization across features
  • Difficulty communicating trade-offs to stakeholders
  • Time wasted rebuilding priority matrices every quarter
The insight: PMs don’t need another spreadsheet — they need a tool that enforces consistent scoring, visualizes trade-offs, and produces artifacts they can share in planning meetings.

User Segments

Segment Profile Primary Need
IC PMs (Primary) Mid-level PMs at B2B SaaS companies (2–8 years experience), managing 10–30 feature requests per quarter, currently using spreadsheets or Notion tables Present prioritization rationale to leadership with consistent, defensible scoring
PM Leaders (Secondary) Directors/VPs reviewing team prioritization proposals Quick visual summary for alignment; value consistency across teams

User Stories

Prioritization Frameworks

The tool supports three industry-standard frameworks, each suited to different decision contexts:

RICE Score

RICE = (Reach × Impact × Confidence) / Effort

// Reach: How many users impacted per quarter? (numeric)
// Impact: Per-user impact magnitude:
Minimal → 0.25  |  Low → 0.5  |  Medium → 1  |  High → 2  |  Massive → 3

// Confidence: How confident in estimates? (50–100%)
// Effort: Person-months required (numeric)

ICE Score

ICE = Impact × Confidence × Ease

// Impact: 1–10 scale
// Confidence: 1–10 scale
// Ease: 1–10 scale (inverse of effort)

Value vs. Effort (2×2 Matrix)

// Value: 1–10 scale (combines reach + impact)
// Effort: 1–10 scale

Quadrants:
High Value + Low Effort → Quick Wins
High Value + High Effort → Big Bets
Low Value + Low Effort → Fill-Ins
Low Value + High Effort → Money Pit

Feature Requirements (v1)

Must Have

ID Requirement Details
FR-01 Add/edit/delete features Each feature has a name, description, and framework-specific scores
FR-02 RICE score calculator Auto-computed priority score from Reach, Impact, Confidence, and Effort inputs
FR-03 Visual 2×2 matrix Scatter plot with features plotted by value vs. effort, with labeled quadrants
FR-04 Ranked list view Features sorted by priority score in descending order
FR-05 Data persistence All features and scores persist to localStorage and survive page refreshes
FR-06 Dark theme Consistent with portfolio project aesthetic

Should Have

  • Toggle between RICE and ICE frameworks
  • Copy prioritization as formatted markdown
  • Color-code features by category/theme
  • Hover/click on matrix dots to see feature details

Could Have

  • AI-generated prioritization suggestions based on feature descriptions
  • Import features from a pasted list (CSV or plain text)
  • Export as PNG image for slide decks

Technical Architecture (v1)

  • Frontend: React 18 with Vite (same stack as meeting-summarizer)
  • Visualization: Recharts for the scatter plot / matrix visualization
  • Styling: Inline CSS with dark theme
  • Persistence: localStorage for all feature data and scores
  • Hosting: Fully client-side — no backend required
Architecture decision: React with Vite was chosen for this project (vs. CDN-loaded React in the To-Do Prioritizer) because the scatter plot visualization benefits from proper module imports via Recharts. The build step is a worthwhile trade-off for charting capabilities.

Risks & Mitigations

Risk Impact Mitigation
Scatter plot readability with many features Medium Limit to 20 features; add hover tooltips for detail
Users unfamiliar with RICE/ICE frameworks High Add inline tooltips explaining each dimension with examples
localStorage limits (~5MB) Low Unlikely with text-only data; add export as backup

Out of Scope (v1)

Explicitly excluded to ship a focused MVP:
  • Multi-user collaboration — single-user tool only
  • Backend or database — localStorage only
  • Integration with Jira, Linear, or Asana
  • Historical tracking of score changes over time
  • Mobile optimization — desktop-first for v1
v1 constraint: This is a portfolio project — visual polish and clear PM thinking are prioritized over edge-case handling.
